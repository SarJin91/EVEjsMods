# hotPathPerf: sources

Loader pattern (`Module._load` hook, probe after 60 s, silence in helper processes) taken from the local mod `mods/scenePerfFix/`.

- `lib/dungeonActiveIndex.js` `buildSummary`: a fragment of EveJS (`server/src/services/dungeon/dungeonRuntimeState.js` `buildInstanceSummary`, 261028.1), same licence as the server.
- `lib/careerAbyssalRead.js`: the classification predicate (`siteFamily === "abyssal" && siteKind === "abyssal-pocket"`) mirrors `server/src/services/career/careerAbyssalSources.js` `runFrom`, and the segment-free path mirrors `getSegments` in `server/src/gameStore/index.js` (EveJS 261028.1), same licence as the server. The result is assembled by calling the vendor `sqliteStore.assembleFromRows` (no copy).
- `lib/careerCombatItemsRead.js`: the ledger key `__evejsCareerCombatOutcomes` and the `items` table from `server/src/services/inventory/itemStore.js` `listPendingCareerCombatOutcomes` (EveJS 261028.1), no code copied; the result is assembled by calling the vendor `sqliteStore.assembleFromRows`.
- `lib/templateReadOnly.js`: serves the vendor `dungeonAuthority.getTemplateByIDReadOnly` (`server/src/services/dungeon/dungeonAuthority.js`, an adaptation of ciefa/evejs-ciefa-fork according to the vendor comment), no code copied.
- `lib/structuresSystemFilter.js`: `toPositiveInt` and `cloneValue` copied from `server/src/services/structure/structureState.js` (EveJS 261028.1), same licence as the server; the filter calls the vendor `peekStructuresForSystem` and `tickStructures` (no copy).
- `lib/dronePersistCoalesce.js`: no external code; follows the pattern of the mod's own `lib/rockRemainderCoalesce.js` (buffer, `unref` timer, flush-before, shutdown hook). The list of movement fields mirrors the keys of `serializeDroneSpaceState` in `server/src/services/drone/droneRuntime.js` (EveJS 261028.1), no code copied.
- `lib/tickStructuresThrottle.js`: no external code; wraps the vendor `tickStructures` (`server/src/services/structure/structureState.js`) and `SpaceRuntime.prototype.tick`, no logic copied.
- `lib/blueprintOwnerRead.js`: the `listBlueprintInstancesByOwner` loop (`server/src/services/industry/industryRuntimeState.js:1308-1344`) and `toInt` (`:214-217`) ported 1:1 from EveJS 261028.1, same licence as the server; the loop body calls the original vendor `getBlueprintByItemID` (no copy). `test/hotpath12.js` runs, in `vm`, function bodies cut from the text of that file (no copy in the mod repository).
- `lib/nativeWreckList.js`: the `isPendingMiningWreck` predicate and the `listNativeWrecks` loop (filter + sort) ported 1:1 from `server/src/space/npc/nativeNpcStore.js` (EveJS 261108.1), same licence as the server; the predicate calls the vendor exports `nativeNpcDeathWrecks.isPendingWreck` and `incursionDeathWrecks.isPending` (no copy).
- `lib/sovCaptureEchoSkip.js`: `normalizePositiveInteger` and `clampScore` copied from `server/src/services/sovereignty/sovCaptureState.js:42-49, 79-85`, and the `hasBlockedWinner` condition from `:826-843` (EveJS 261108.1), same licence as the server. Copied because the mask predicate must give exactly the same result as the vendor reconcile loop (the functions are local, not exported); `test/hotpath19.js` checks that the text still matches. `TYPE_INFRASTRUCTURE_HUB` from `sovConstants.js:10`.
- `lib/cynoBroadcastFilter.js`: `normalizePositiveInteger` (with `normalizeInteger`) copied from `server/src/services/sovereignty/sovSuppressionState.js:41-53`, and the session system match (`solarsystemid2 || solarsystemid`) from `getTargetSessions` in `sovNotifications.js:44-75` (EveJS 261108.1), same licence as the server. Copied because the filter must skip exactly the systems where the vendor would not send a notification; `test/hotpath20.js` checks that the text still matches.
- `lib/incursionTalesMemo.js`: the `getTales` / `activeTales` / `forSystem` filters ported 1:1 from `server/src/services/incursion/incursionPresentation.js:43-47` (EveJS 261108.1), same licence as the server (AGPL); the `isPrepared` predicate and the `incursionLifecycle.listTales` list are calls to vendor exports (no copy). A file fingerprint checks that they still match (`test/hotpathIncursion.js`).
- `lib/sceneRetention.js` `dockedSystemOf` / `inSpaceSystemOf`: the session rule (docked first, then `_space.systemID`) from the local mod `mods/livingNewEden/lib/adapter/sessionPresence.js` `recordOf` (same project), extended with the field variants from `server/src/services/structure/structureLocation.js`.
